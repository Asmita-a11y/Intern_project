Git & GitHub Commands

S.N Command Purpose
1 git init Create a new Git repository
2 git clone <url> Copy a repository to your computer
3 git status Check the current state of files
4 git add . Stage all changed files
5 git commit -m "message" Save staged changes with a message
6 git push Upload commits to GitHub
7 git pull Download and merge latest changes
8 git branch List all branches
9 git checkout -b <name> Create and switch to a new branch
10 git merge <branch> Merge a branch into the current one
11 git log View commit history
